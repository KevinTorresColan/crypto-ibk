## Principios de Desarrollo

Al evolucionar `ibk-crypto`, seguiremos estos principios:

1. **Seguridad primero**: Nunca comprometer la seguridad por features
2. **Compatibilidad hacia atrás**: Minimizar breaking changes entre versiones
3. **Rendimiento**: Optimizar sin sacrificar legibilidad y mantenibilidad
4. **Simplicidad**: API intuitiva, clara y fácil de usar
5. **Documentación**: Mantener documentación actualizada y completa
6. **Estándares**: Adherirse a estándares web (W3C, WHATWG)
7. **Testing**: Cobertura de tests exhaustiva para garantizar calidad
8. **Clean Code**: Código limpio, mantenible y auto-documentado
